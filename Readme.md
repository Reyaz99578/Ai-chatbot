# 🤖 Reyaz's AI Chatbot

An interactive AI chatbot built using Python, Streamlit, and the Groq API.

## Features
- 💬 Interactive chat interface
- ⚡ Fast AI-powered responses
- 🌐 Replies in the user's language
- 🧹 Clear chat history
- 🎛️ Select AI models and adjust temperature

## Technologies Used
- Python
- Streamlit
- Groq API

## Run Locally
1. Install dependencies:
   `pip install -r requirements.txt`
2. Configure your `GROQ_API_KEY` in Streamlit secrets or your local secrets configuration.
3. Run the app:
   `streamlit run app.py`
